# Сравнение моделей компьютерного зрения YOLOv8

## Описание

Учебная практика

Цель проекта — сравнение различных моделей семейства YOLOv8 для обнаружения объектов на изображениях.

## Используемые технологии

- Python 3.13
- PyTorch
- Ultralytics YOLOv8
- OpenCV
- Matplotlib

## Структура проекта

```
data/
images/
models/
results/
src/
report/
```

## Запуск

```bash
python src/compare_models.py
```
